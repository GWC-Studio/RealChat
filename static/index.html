控制 AI 回复前的推理深度。启用后 AI 会先内部思考再回答，回复质量更高但更慢。
对 DeepSeek Chat 使用 thinking 参数，对 OpenAI 使用 reasoning_effort。

等级越高，思考 token 越多，回复质量越高但延迟越大
